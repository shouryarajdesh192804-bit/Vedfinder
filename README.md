# 🦊 VedFinder

A futuristic search engine built using Flask.

## Features

- Bing + Wikipedia Knowledge Card
- DuckDuckGo Web Results
- DuckDuckGo Images
- GoMode
- Voice Search
- Login / Signup
- Search History
- Dark / Light Mode
- Responsive UI
- Render Deployment
- Google AdSense Placeholder

---

## Install

```bash
pip install -r requirements.txt
```

---

## Run

```bash
python app.py
```

---

## Deploy

```
gunicorn app:app
```
